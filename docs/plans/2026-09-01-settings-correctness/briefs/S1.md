## The rule you are implementing

**The collector is configured from the settings stored in the database the rows are going into.**

- `collect --json` with **no** `--sqlite` stays hermetic: default collector, no settings read, no database opened or created. This is deliberate — making it consult `default_sqlite_url()` would let a bare debug command touch and potentially create the live database.
- `collect --json --sqlite <db>` loads **that** database's settings and configures the collector **before** collecting.
