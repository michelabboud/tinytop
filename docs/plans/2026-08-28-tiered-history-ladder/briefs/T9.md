**F1 — Surface in `disk.rs` (additive beside ADR 0017's functions).**
```rust
pub trait FreeBytesProvider: Send + Sync {
    fn free_bytes(&self, path: &Path) -> io::Result<u64>;
}
/// The real provider — `free_bytes_at` (sysinfo, longest mount prefix; ADR 0017).
pub struct SysinfoFreeBytes;
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize)] #[serde(rename_all = "camelCase")]
pub enum DiskTransition { Unchanged, Breached, Recovered }
#[derive(Debug, Clone, PartialEq, Serialize)] #[serde(rename_all = "camelCase")]
pub struct DiskCheckReport { pub path: PathBuf, pub free_bytes: i64, pub min_free_bytes: i64, pub database_bytes: i64, pub pressure: bool, pub transition: DiskTransition }
/// Measure + apply. The path measured is the database's PARENT directory (the same path the migration guard passes).
pub async fn check_disk(store: &SqliteHistoryStore, provider: &dyn FreeBytesProvider, ladder: &RetentionLadder, now_ms: i64) -> Result<DiskCheckReport, StoreError>;
/// The state machine over an already-taken measurement (the daemon measures on a blocking thread, then applies).
pub async fn apply_disk_measurement(store: &SqliteHistoryStore, path: &Path, measurement: io::Result<u64>, ladder: &RetentionLadder, now_ms: i64) -> Result<DiskCheckReport, StoreError>;
```
`check_disk` = `apply_disk_measurement(store, dir, provider.free_bytes(dir), ladder, now_ms)`. `u64 → i64` saturates at `i64::MAX`. `database_bytes` = the store's existing private `database_bytes()` (same crate — no visibility change). Re-export from `lib.rs`: `pub use disk::{FreeBytesProvider, SysinfoFreeBytes, DiskCheckReport, DiskTransition, check_disk, apply_disk_measurement}`.

**F2 — The state machine (spec §9 + ADR 0020).** `min = ladder.disk_check.min_free_bytes`; `breach = free < min` (strict, as the spec writes it; no hysteresis — ADR 0020). `previous = history_state_get::<DiskPressureState>("diskPressure")` (`None` ⇒ inactive). Transitions:
- inactive → breach: write `{active:true, sinceMs: now_ms, freeBytes, minFreeBytes}` + marker `diskPressure` (label `Disk pressure: free <bytes> < minFreeBytes <bytes>`, details `{"freeBytes","minFreeBytes","databaseBytes","path"}`) → `Breached`.
- active → breach: write with **`sinceMs` preserved**, fresh `freeBytes`/`minFreeBytes`; NO marker ("once per breach") → `Unchanged`, `pressure: true`.
- active → no breach: write `{active:false, sinceMs: null, freeBytes, minFreeBytes}` + marker `diskRecovered` (label `Disk pressure cleared: free <bytes> ≥ minFreeBytes <bytes>`, same details) → `Recovered`.
- inactive → no breach: write `{active:false, sinceMs: null, freeBytes, minFreeBytes}` (so coverage's `freeBytes` is fresh every check), NO marker → `Unchanged`, `pressure: false`.
On every successful check `lastDiskCheckMs = now_ms`. **State, `lastDiskCheckMs` and the marker commit in ONE transaction** (`pool.begin()`; `history_state_set_on(&mut *tx, …)` twice; a new `record_event_on(&mut SqliteConnection, …)` split out of `record_event` exactly like `history_state_set`/`history_state_set_on` — `record_event` becomes the one-line wrapper) — a kill between them must not leave an active state without its marker or a marker without its state. **Undeterminable** (`measurement` is `Err`): NOTHING is written — state unchanged, `lastDiskCheckMs` unchanged, no marker — and the function returns `Err(StoreError::DiskCheck { path, source })` (new variant: `DiskCheck { path: PathBuf, source: std::io::Error }`; `Display` = `disk check: cannot determine free bytes at <path>: <source>; the last known disk-pressure state is kept — check the mount or set retentionLadder.diskCheck.minFreeBytes`; `std::error::Error::source` returns the io error). Never a `StoreError::Sqlx` for an io failure.
