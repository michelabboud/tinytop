**Design rulings (implement as written; escalate if one cannot work):**

**F1 — Which months are exportable (spec §9 amended by you).** Rows reach the archive only when their hour expires from L4 — with the default ladder (`l4.keepDays = 730`, `coldAfterMonths = 12`) a month's rows arrive one hour at a time, 24 months old; the spec's `M ≤ now − coldAfterMonths` alone would export a month on its first row and the monotone watermark would lock the rest out. A month `M` (UTC `YYYY-MM` of `bucket_start_ms`) is exportable iff ALL of: (a) `M ≤ now − coldAfterMonths` in UTC calendar months; (b) every hour of `M` has expired from main: `end_of_month_ms(M) + l4_keep_ms + 86_400_000 ≤ now_ms` (one day of margin for the move to catch up; `l4.keepDays == 0` or L4 disabled ⇒ nothing is ever exportable — say so in the status output as `reason`); (c) `M > coldExportedUntilMonth` (string compare on zero-padded `YYYY-MM`). Months are exported in ascending order, one file each, in ONE pass per call; the watermark advances after each month. Amend spec §9 `:186` with (b) in one sentence. Month arithmetic uses the workspace `time` crate (`OffsetDateTime::from_unix_timestamp`, `Month`, `Date::from_calendar_date` — `formatting` is the only feature enabled; you need no parsing). Rows that arrive into an already-exported month stay in the queryable archive only — document it in `## Archive` and in `GUIDE.md`.

**F4 — File mechanics.** Target `<directory>/tinytop-1h-YYYY-MM.csv.gz`; write `<target>.tmp` with `flate2::write::GzEncoder::new(file, Compression::new(6))`; header = `ARCHIVE_COLUMNS` in DDL order; each row: integers as decimal, `REAL` through Rust's `{}` `Display` (shortest round-trip), `NULL` ⇒ empty field, fields joined by `,`, records terminated by `\r\n` (RFC 4180 §2.1); a `pub(crate) fn csv_field(raw: &str) -> Cow<str>` quotes a field iff it contains `,`, `"`, CR or LF (doubling `"`), unit-tested with such a string even though numeric rows never need it. `finish()` the encoder, `sync_all()` the file, compute SHA-256 over the finished `.tmp` bytes (`sha2::Sha256`, streamed), then **re-read the `.tmp`** through `flate2::read::GzDecoder`: count data records (== the rows read; a mismatch ⇒ `Err(step "cold verify")`, `.tmp` LEFT IN PLACE, nothing renamed, no manifest row, watermark unchanged), parse the first and last record's first field and compare with the month's `MIN/MAX(bucket_start_ms)`. Then `rename(.tmp, target)` (atomic; a stale target from a crash before its manifest row is overwritten — the manifest, not the file, is the record), fsync the directory (`File::open(dir)?.sync_all()` under `#[cfg(unix)]`), write `<target>.sha256` = `<hex>  <file name>\n` (two spaces; `sha256sum -c` compatible), upsert the manifest row (`INSERT OR REPLACE`), advance the watermark.
