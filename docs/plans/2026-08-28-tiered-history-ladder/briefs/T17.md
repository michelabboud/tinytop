**F2 — the hwmon reader: a pure, OS-independent module tested against fixture trees (ADR 0026 decisions 4, 5, 8; fact sheet §A is the fixture truth).** New `agent/crates/tinytop-collectors/src/thermal.rs`, declared `pub(crate) mod thermal;` in `lib.rs` **without any `cfg`** (it is path-driven and compiles and tests on every OS — that is what makes it provable here). Rules, each one a measured observation from §A: iterate the entries of `hwmon_root` **sorted by file name** (`read_dir` order is not defined — sort, so `<k>` is deterministic); a missing `hwmon_root` (WSL2) → an empty `ThermalScan`, **never an error and never a log line per poll**; read `<entry>/name`, trim it — **empty or unreadable → skip and count in `skipped_unnamed_chips`** (trashcan `hwmon1` is exactly this and must not become a chip named `""`); a name not in `CPU_CHIP_ALLOW_LIST` and not in `extra_chips` → skip and count in `skipped_chips` (this is what keeps `amdgpu`, already reported as `gpus[].temperatureC`, and `nvme`, a later slice, out of T17 **by construction** — ADR 0026 decision 5); for an accepted chip, `<k>` = the number of **already-accepted-or-skipped chips with the same trimmed `name` seen earlier in sorted order** (so a dual-socket box's second `coretemp` is `-1`); within the chip, find every `temp<N>_input` (N parsed as a decimal integer, sorted numerically — `temp10` sorts after `temp2`), `label` = the trimmed content of `temp<N>_label` when it exists and is non-empty, else the literal `temp<N>`; `stable_id` = `format!("hwmon-{chip}-{k}-temp{n}")` — **the `hwmonN` directory index NEVER appears in it** (ADR 0026 decision 1: `coretemp` is `hwmon1` on sheep and `hwmon0` on trashcan; using the index would fork one sensor's history at a reboot). `read_values`: for each sensor, read `temp<N>_input` → an `i64` of millidegrees → `value` = `m as f64 / 1000.0`; an unreadable or unparsable `_input` → **that sensor is omitted from the result** (a disappearing sensor is absence, not a zero); `max` from `temp<N>_max`, `crit` from `temp<N>_crit`, each accepted **only when it parses AND `0.0 < c && c <= 200.0`** (ADR 0026 decision 4), else `None` — sheep's `nvme temp2_max` 65261850 m°C = 65261.85 °C is rejected by that band, and `amdgpu`'s absent `_max` is `None`; `kind` is always `SensorKind::Temp`; `chip` is the trimmed name **verbatim** (never "Intel", never a prettified string).
